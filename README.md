# Hyperbole

A class system prototype inspired by Atlus RPGs, built as a way to explore alternative game design ideas while learning Vue.

**Live demo:** https://sergiorollan.com/hyperbole

---

## About

Hyperbole is an experimental project that reimagines the class (archetype) progression systems found in games like *Metaphor: ReFantazio* and the *Persona* series.

Rather than recreating those systems one-to-one, the goal is to explore different design decisions around:

- Class progression
- Stat distribution
- Skill inheritance
- Combat attributes
- Archetype identity
- Party customization

The project acts as an interactive design document where every archetype, skill tree and combat rule can be explored visually.

---

## Why I built it

This project had two goals:

- Learn Vue by building something larger than a tutorial project.
- Put into practice a number of game design ideas that had been sitting in my notes for years.

I've always enjoyed thinking about RPG progression systems, and Hyperbole became a good excuse to organize those ideas into something interactive instead of leaving them as documents.

- Interactive archetype browser

## Disclaimer

Hyperbole is a **fan-inspired design exercise**.

It takes visual inspiration from Atlus games, especially *Metaphor: ReFantazio*, but it is **not intended to reproduce their mechanics**. The objective is to propose alternative systems and balance ideas rather than create a clone.
